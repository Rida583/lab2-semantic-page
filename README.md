# Lab 2 - Semantic Profile Page

This project is a simple semantic HTML profile page.

## Features

- Semantic HTML structure
- About Me section
- Skills list
- Timeline
- Fun Fact
- Contact form
- HTML form validation
- JavaScript localStorage
- Clear Saved Data button

## Files

- index.html
- script.js
- README.md

## How to Run

Open `index.html` in a web browser or use Live Server in VS Code.
